# 13 November 2026 world news in one image

[![make.fun](https://img.shields.io/badge/make.fun-news--image--01-blue)](https://make.fun/bounty/news-image-01)
[![make.fun](https://img.shields.io/badge/make.fun-entry-green)](https://make.fun)

A program that writes one image summing up 13 November 2026 world news to `/output/entry.png`.

The image is a front page for Friday 13 November 2026: a globe illustration with a
plane, a computer chip, an oil barrel and a newspaper, headed "13 NOVEMBER 2026 —
THE WORLD IN ONE IMAGE", with the day's headlines listed below: the FAA lifting its
US ground stop after a four-hour communications failure, Nvidia CEO Jensen Huang
resigning, Iran claiming a strike on a US radar in Bahrain, China's large Pacific
naval drills, the IEA forecasting a Q4 oil surplus, Qatar and Turkey signing a
defence pact, and the Microsoft 365 outage recovering.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` (a JPEG, 1024x1024, under 1 MiB) to the output directory.
